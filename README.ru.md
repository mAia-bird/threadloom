Threadloom — крошечный личный Telegram-бот. Ты присылаешь ему пост; он режет текст
на нормальный тред (корневой пост + реплаи, каждый в пределах лимита Threads в 500
знаков), показывает превью и — по нажатию **«Опубликовать»** — постит весь тред в
[Meta Threads](https://www.threads.net).

```
Ты в Telegram  ──▶  🧵 бот Threadloom  ──▶  превью + кнопки  ──▶  Meta Threads
  «длинный пост»       режет на тред        📤 Опубликовать        тред опубликован
```

**Никаких зависимостей** — только стандартная библиотека Python — и дружелюбный
мастер настройки, который проведёт тебя через каждый токен по шагам. Всё работает
на твоём компьютере; токены никуда не уходят.

## Чем хорош

- ✍️ **Черновик в Telegram, публикация в Threads.** В Telegram удобно писать, а тред
  уходит в Threads.
- ✂️ **Автонарезка на тред.** Длинные посты превращаются в аккуратный тред с учётом
  абзацев и предложений. Не нужно вручную резать по 500 знаков.
- 🔒 **Приватно по умолчанию.** Управлять ботом может только *твой* аккаунт.
- 🧰 **Настройка без боли.** `python run.py` запускает мастер: создаёт бота, сам
  узнаёт твой ID и проверяет каждый токен.
- 🤖 **Своя нейросеть (по желанию).** Хочешь нарезку поумнее? Подключи любой
  OpenAI-совместимый эндпоинт (OpenAI, OpenRouter, локальный Ollama/LM Studio) или
  Anthropic. По умолчанию выключено — встроенной нарезке ключи не нужны.

## Что нужно

- Python **3.9 или новее**. И всё. Никаких `pip install` и виртуальных окружений.
- Аккаунт Telegram и аккаунт [Threads](https://www.threads.net).

## Быстрый старт

```bash
git clone https://github.com/mayamastra/threadloom.git
cd threadloom
python run.py
```

Первый запуск поднимает мастер настройки. Пройди его, затем снова запусти
`python run.py`. Открой Telegram, пришли боту пост и нажми
**📤 Опубликовать в Threads**.

## Мастер настройки по шагам

`python run.py` при первом запуске (или `python run.py setup` в любой момент)
запускает интерактивный гид. Вот что именно он спрашивает и как это получить.

### 1. Токен Telegram-бота

Мастер попросит:

1. Открыть Telegram и написать **[@BotFather](https://t.me/BotFather)** (у него синяя
   галочка).
2. Отправить `/newbot`.
3. Задать **отображаемое имя** (например, *My Threadloom*).
4. Задать **username**, заканчивающийся на `bot` (например, `my_threadloom_bot`).
5. BotFather пришлёт **токен** вида `123456789:AAExxxxx…`.
6. Вставить токен в мастер. Он проверит токен через Telegram и подтвердит имя бота.

### 2. Твой Telegram ID (ловится автоматически)

Чтобы ботом пользовалась *только ты*, Threadloom нужен твой числовой Telegram ID.
Искать его не надо: мастер говорит *«напиши своему боту»*, ты отправляешь ему любое
сообщение («привет»), и он сам подхватывает твой ID. (При желании можно вставить
вручную — ID подскажет [@userinfobot](https://t.me/userinfobot).)

### 3. Доступ к Meta Threads (самое муторное)

Это разовая настройка на сайте для разработчиков Meta. Мастер даёт краткую версию;
вот полная:

1. Убедись, что есть **аккаунт Threads** ([threads.net](https://www.threads.net)).
2. Зайди на **[developers.facebook.com](https://developers.facebook.com/)** и залогинься.
3. Нажми **Create App**. На вопрос, что ты создаёшь, выбери сценарий
   **«Access the Threads API»** и доведи создание до конца.
4. Открой use case **Threads** в приложении и добавь права:
   - `threads_basic`
   - `threads_content_publish`
5. Добавь себя как **Threads-тестировщика** и прими приглашение внутри приложения
   Threads (**Настройки → Аккаунт → Разрешения для сайтов**).
6. Сгенерируй **user access token** для своего аккаунта и скопируй его.
7. Вставь токен в мастер. Он вызовет Threads API, проверит токен и **сам определит
   твой Threads user ID** — так что вставлять нужно только токен.

> 📎 Официальная инструкция Meta со скриншотами:
> <https://developers.facebook.com/docs/threads/get-started>

Этот шаг можно пока пропустить (просто нажми Enter) и добавить позже — бот всё равно
запустится, просто не будет публиковать, пока Threads не подключён.

> ⏳ **Токены протухают.** Access-токен Threads живёт около 60 дней. Когда истечёт —
> сгенерируй новый и перезапусти `python run.py setup` (или обнови
> `THREADS_ACCESS_TOKEN` в `.env`). См.
> [долгоживущие токены](https://developers.facebook.com/docs/threads/get-started/long-lived-tokens).

### 4. Умная нарезка своей нейросетью (по желанию)

По умолчанию Threadloom режет посты сам — без ключей, работает офлайн. Если хочешь,
чтобы нарезкой занималась нейросеть (аккуратнее переходы, сильнее первая строка),
мастер даёт её подключить:

- **OpenAI-совместимый** — OpenAI, OpenRouter, Together или **локальный** сервер вроде
  [Ollama](https://ollama.com) (`http://localhost:11434/v1`) или LM Studio.
- **Anthropic** — модели Claude.

Если модель сорвётся или вернёт ерунду, Threadloom тихо переключится на встроенную
нарезку — публикация не сломается.

## Как пользоваться

Запуск:

```bash
python run.py
```

Дальше в Telegram:

- **Пришли любой пост** обычным сообщением → бот ответит превью треда с кнопками.
- **📤 Опубликовать в Threads** — публикует тред; в ответ придёт ссылка на него.
- **✂️ Перенарезать** — режет тот же пост заново (удобно после включения нейросети).
- **✖️ Отмена** — выбрасывает превью.

Команды: `/start`, `/help`.

### Чтобы бот работал постоянно

`python run.py` работает в переднем плане. Чтобы не закрывался вместе с терминалом,
самое простое:

```bash
nohup python run.py > threadloom.log 2>&1 &
```

На macOS можно завернуть в агент `launchd`, на Linux — в `systemd --user`. Подойдёт
любой менеджер процессов — это обычная программа на Python.

## Справочник настроек

Всё, что пишет мастер, лежит в `.env` (в `.gitignore`). Можно править руками; см.
аннотированный шаблон [`.env.example`](.env.example).

| Переменная | Что это |
| --- | --- |
| `LANG_UI` | Язык интерфейса: `en` или `ru`. |
| `TELEGRAM_TOKEN` | Токен бота от @BotFather. |
| `OWNER_ID` | Твой числовой Telegram ID — единственный аккаунт, которому можно пользоваться ботом. |
| `THREADS_ACCESS_TOKEN` | Access-токен Meta Threads. |
| `THREADS_USER_ID` | Твой Threads user ID (подставляется автоматически из токена). |
| `THREADS_CTA` | Необязательный финальный пост в конце каждого треда (≤ 500 знаков), например ссылка на канал. |
| `LLM_ENABLED` | `true` — резать нейросетью, иначе встроенная нарезка. |
| `LLM_PROVIDER` | `openai` (любой OpenAI-совместимый) или `anthropic`. |
| `LLM_API_BASE` | Base URL API, например `https://api.openai.com/v1` или `http://localhost:11434/v1`. |
| `LLM_API_KEY` | API-ключ (пусто — для локального сервера без ключа). |
| `LLM_MODEL` | Название модели, например `gpt-4o-mini`, `llama3.1`, `claude-haiku-4-5`. |

## Если что-то не так

- **«Telegram не принял токен».** Скопирован не весь токен или затесался пробел.
  Скопируй заново у BotFather.
- **Мастер не поймал ID.** Проверь, что написала *нужному* боту (`@твой_бот`), и дай
  ему подождать, либо вставь ID из [@userinfobot](https://t.me/userinfobot).
- **Публикация падает с ошибкой Threads API.** Обычно истёк токен (~60 дней) или нет
  права `threads_content_publish`. Сгенерируй токен заново и запусти
  `python run.py setup`.
- **Пост не влезает.** Каждый пост Threads — максимум 500 знаков. Threadloom режет
  сам; если одно неразрывное слово (огромный URL) длиннее 500 — оно разрежется как
  крайняя мера.

## Как это устроено

Маленько и читаемо — четыре части, всё на стандартной библиотеке:

| Файл | Роль |
| --- | --- |
| `threadloom/telegram_api.py` | Минимальный клиент Telegram Bot API (long polling). |
| `threadloom/threads_api.py` | Публикация треда через Threads Graph API. |
| `threadloom/splitter.py` | Встроенная нарезка (абзацы → предложения → слова). |
| `threadloom/llm.py` | Опциональная нарезка нейросетью (OpenAI-совместимый / Anthropic). |
| `threadloom/bot.py` | Связывает всё: превью, кнопки, публикация. |
| `threadloom/setup_wizard.py` | Интерактивная настройка при первом запуске. |
